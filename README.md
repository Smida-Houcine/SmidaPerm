# SmidaPerm
EViews programs for generating permutations of a set of elements using Smida's Row Insertion Permutation Algorithm (RIPA).  

## Description
This repository provides **SmidaPerm**, EViews programs implementing Smida's Row Insertion Permutation Algorithm (RIPA) for permutation generation. Two implementations are provided: an iterative implementation and a recursive implementation.  

## Requirements
• EViews version: Implemented and tested in EViews 13.  
• Operating System: Windows 10/11.  

## Files
This repository is composed of the following files:  

• `smida_permutation_iterative.prg`: Source code of the iterative implementation.  
• `smida_permutation_iterative.aipz`: Add-in installer for the iterative implementation.  
• `smida_permutation_iterative_version_0.prg`: Version 0 of the iterative implementation.  
• `smida_permutation_recursive.prg`: Source code of the recursive implementation.  
• `smida_permutation_recursive.aipz`: Add-in installer for the recursive implementation.  
• `smida_permutation_recursive_version_0.prg`: Version 0 of the recursive implementation.  

## EViews Add-in
The iterative implementation is available as the **“smidaperm”** Add-in on the official EViews Add-ins page:  
http://www.eviews.com/Addins/smidaperm.aipz  

## For Developers / Researchers
The `.prg` files can be opened and executed directly in EViews. They are provided to study, modify, or extend the implementations.  

## For Experienced Users
The `.aipz` files are provided as compressed EViews Add-in installers for direct installation within EViews. To install an Add-in, simply run the corresponding `.aipz` file and follow the on-screen instructions within EViews.  

The installed Add-in appears in the EViews Add-ins menu.
