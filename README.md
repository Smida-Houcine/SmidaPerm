# SmidaPerm
EViews program for generating permutations of a set of elements using Smida's algorithm.  
**Description:**   
This repository provides **SmidaPerm**, an EViews program that implements Smida’s algorithm for permutation generation.         
**Requirements:**  
• EViews version: Implemented in EViews 13 and tested in EViews 10.   
• Operating System: Windows 10/11.    
**Files:**  
This repository is composed by the files:   
• SmidaPerm.prg: Main source code.    
• LICENSE: License file.   
• README.md: Readme file.       
• SmidaPerm.aipz: Add-in Installer.   
## Note
The "SmidaPerm.aipz" file is **optional**. To study, modify, or extend the algorithm, it is recommended to use "**SmidaPerm.prg**".  
## For Developers / Researchers:
1. Copy "SmidaPerm.prg" into EViews.
2. Run the file to use or modify the algorithm directly.
  
## For Experienced Users: 
The Add-in "SmidaPerm.aipz" is provided as a compressed **.aipz** file for direct installation within EViews. It is also downloadable from: http://www.eviews.com/Addins/smidaperm.aipz    
**Add-in Installer:**   
To install the Add-in, simply run the **.aipz** installer and follow the on-screen instructions within EViews.  
The provided installer automates both the installation and internal registration of the Add-in within the EViews environment.    
Once installed, the Add-in **appears** in the EViews Add-ins menu as “**Smida's Permutation**”.
